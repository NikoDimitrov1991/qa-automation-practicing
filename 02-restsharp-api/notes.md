### Why API testing beats UI testing (from Lecture 1)

- ~100x faster (milliseconds vs. 20-30 sec per test)
- ~10x more stable (no CSS selectors to break)
- Runs independently of frontend
- Golden standard for automation in modern QA teams

### NUnit vs Java JUnit

Very similar APIs. C# uses `[]` for attributes (Java `@` for annotations). Most concepts transfer 1:1:

| NUnit | JUnit |
|-------|-------|
| `[Test]` | `@Test` |
| `[TestFixture]` | `@RunWith` / not always required |
| `[SetUp]` | `@Before` (JUnit 4) / `@BeforeEach` (JUnit 5) |
| `[TearDown]` | `@After` / `@AfterEach` |
| `Assert.That(actual, Is.EqualTo(expected))` | `assertEquals(expected, actual)` |
